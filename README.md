# Palm Manual Prototype v0.1

手のひらの写真を使った「人物取扱説明書AI」の**UX検証用モック**です。

> 手を撮るだけで、あなたの取扱説明書が生まれる。

## これは何か

- スマートフォンで **「名前入力 → 左手 → 右手 → 診断中 → 結果」** までを気持ちよく体験してもらうためのプロトタイプです。
- 本物のAI手相解析・人物解析は**まだ実装していません**。結果はシード（名前・画像ファイル名・サイズなど）から決定的に生成されるモックです。
- 同じ入力なら同じ結果が比較的安定して出ます（純粋な `Math.random()` ではありません）。

## 技術構成

- **HTML / CSS / JavaScript のみ**（フレームワーク・ビルド工程なし）
- 外部API・APIキー未使用
- 写真は**送信・保存しません**。選択した画像はブラウザ内でローカルプレビュー表示するだけです。
- **GitHub Pages でそのまま公開可能**な静的Webアプリ
- スマートフォン優先のレスポンシブUI（ダーク基調・光/霧/ガラス表現）

## ファイル構成

```
palm-manual/
├─ index.html      … 画面構造（SPA）
├─ style.css       … デザイン（スマホ優先）
├─ app.js          … 画面遷移・写真プレビュー・演出・結果描画
├─ diagnosis.js    … モック診断ロジック（シード生成・結果パターン）
├─ types.js        … 6属性システム
└─ README.md
```

## 起動方法

`index.html` をブラウザで直接開くだけで動作します（ローカルファイル）。

サーバー起動が不要なので、`npx serve` などに依存しません。

## 画面フロー

1. **TOP** — タイトルと「診断してみる」
2. **名前入力** — ニックネームでもOK（未入力は進めない）
3. **左手写真** — プレビュー・撮り直し・これでOK
4. **右手写真** — 同上
5. **ANALYZING** — 演出（約3秒）
6. **RESULT** — 属性 / 固有愛称 / 特徴 / 取扱説明書 / 将来ボタン / もう一度診断

## 属性（6種）

| 英語 | 日本語 | 意味 |
|---|---|---|
| WIND | 風 | 世界を広げる人 |
| PRISM | 光 | 世界をつなぐ人 |
| TIDE | 水 | 人を感じる人 |
| ROOT | 樹 | 世界を育てる人 |
| FORGE | 火 | 世界を動かす人 |
| VEIL | 月 | 世界を深く見る人 |

## 禁止事項・方針

- AI解析をしていると偽装しない
- 「科学的に性格がわかる」とは書かない
- 健康・寿命・病気・妊娠・犯罪・投資等は診断しない
- ログイン機能・DBを作らない
- 不要ライブラリ・npm必須環境・React等へは変更しない
