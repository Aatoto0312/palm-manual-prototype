# Palm Manual Prototype v0.1.1

手のひらの写真を使った「人物取扱説明書AI」の**UX検証用モック**です。

> 怪しい手相占いではなく、
> 「手を入口に、その人専用の取扱説明書を生成するプライバシー重視のエンタメ体験」として見せることを目的としています。

## これは何か

- スマートフォンで **「ニックネーム入力 → 左手 → 右手 → 診断中 → 結果」** までを気持ちよく体験してもらうためのプロトタイプです。
- 本物のAI手相解析・人物解析は**まだ実装していません**。結果はシード（ニックネーム・画像ファイル名・サイズなど）から決定的に生成されるモックです。
- 同じ入力なら同じ結果が比較的安定して出ます（純粋な `Math.random()` ではありません）。

## v0.1.1 での変更

### バグ修正
- 名前入力画面の「次へ」ボタンを正常動作させた（Enterキーでも動作）
- 画面遷移時にスクロール位置を常に上端へ戻すようにした
- RESULTの第一属性の二重表記（例: 「風 / WIND」）を解消

### 名前入力の表現変更
- 「名前」ではなく **「表示名 / ニックネーム」** として入力
- 表記: 「あなたを何と呼べばいい？ / 本名じゃなくてOK。ニックネームでも大丈夫です。」

### Privacy UX
- TOPにプライバシー3項目を明示
  - 🔒 手の写真は保存されません
  - 👤 本名・会員登録は不要です
  - 🔗 友達に共有されるのは診断結果だけです
- 結果画面のシェア部分に「共有されるのは結果だけ。元の手の写真は含まれません。」を明示
- 実装と矛盾しないように、端末内ローカルのみの動作である表現に合わせている

### RESULT大幅強化（詳しい取扱説明書）
従来の下記に加えて、**「詳しい取扱説明書」**（8セクション）を追加し、結果全体で約800〜1500字程度読める構成にしました。

- 第一属性 / 第二属性 / 固有タイトル / ★特徴3つ / 取扱説明書5項目（従来どおり）
- A. あなたはこんな人（200〜300字の総評）
- B. 思考のクセ
- C. 人との関わり方
- D. 動き出す条件
- E. バグ発生条件
- F. 再起動方法
- G. 誤解されやすいところ
- H. 隠し機能

文章は単一の気質ではなく**複数特徴の組み合わせ**から構成し、
「この結果はこの人の組み合わせだから出ている」と感じられる書き方にしています。
また科学的な断定はせず、「この診断では〜として読みます」という独自解釈の枠組みで記述しています。

### 「どうしてこの結果になった？」
- RESULT下部に折りたたみ領域を追加
- モックであること・今後は複数特徴の組み合わせで生成予定であることを明記
- 本物の生命線・知能線などは表示しない（捏造しない）

## 技術構成

- **HTML / CSS / JavaScript のみ**（フレームワーク・ビルド工程なし）
- 外部API・APIキー未使用
- 写真は**送信・保存しません**。選択した画像はブラウザ内でローカルプレビュー表示するだけです。
- **GitHub Pages でそのまま公開可能**な静的Webアプリ
- スマートフォン優先のレスポンシブUI（ダーク基調・光/霧/ガラス表現）

## ファイル構成

```
palm-manual/
├─ index.html      … 画面構造（SPA）
├─ style.css       … デザイン（スマホ優先・長文対応）
├─ app.js          … 画面遷移・写真プレビュー・演出・結果描画
├─ diagnosis.js    … モック診断ロジック（シード生成・結果パターン・詳しい取扱説明書）
├─ types.js        … 6属性システム
└─ README.md
```

## 起動方法

`index.html` をブラウザで直接開くだけで動作します（ローカルファイル）。

サーバー起動が不要なので、`npx serve` などに依存しません。

## 画面フロー

1. **TOP** — タイトル・プライバシー3項目・「診断してみる」
2. **ニックネーム入力** — 本名不要でOK（未入力は進めない）
3. **左手写真** — プレビュー・撮り直し・これでOK
4. **右手写真** — 同上
5. **ANALYZING** — 演出（約3秒）
6. **RESULT** — 属性 / 固有愛称 / 特徴 / 取扱説明書 / 詳しい取扱説明書 / 「どう読んだ？」 / 将来ボタン（シェア注記つき）/ もう一度診断

## 禁止事項・方針

- AI解析をしていると偽装しない
- 「科学的に性格がわかる」とは書かない
- 健康・寿命・病気・妊娠・犯罪・投資等は診断しない
- ログイン機能・DBを作らない
- 不要ライブラリ・npm必須環境・React等へは変更しない
